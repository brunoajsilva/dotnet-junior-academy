# .NET Backend Academy

Site de ensino de .NET para programadores de backend. Um único ficheiro HTML gerado por Python.

- **Ver o site**: `index.html` (publicado com GitHub Pages).
- **Evoluir com IA**: lê `AGENTS.md`. Há um prompt pronto em `prompts/novo-modulo.md`.
- **Documentação**: `docs/` (escrever conteúdo, esquema, estilo, design, build).

Gerar localmente: `python3 src/build.py --out index.html`
